# Project 2 - Exploratory Data Analysis (EDA)

## Objective

To perform Exploratory Data Analysis on an E-Commerce dataset and identify meaningful business insights.

## Tools Used

  Google Sheets
  Microsoft Excel
  Statistical Functions

## Analysis Performed

  Total Orders
  Average Quantity
  Median Quantity
  Average Unit Price
  Median Unit Price
  Average Total Price
  Median Total Price
  Most Sold Product
  Most Used Payment Method
  Most Used Coupon Code
  Most Common Order Status

## Conclusion

The project successfully analyzed the dataset and extracted valuable business insights using Exploratory Data Analysis techniques.
